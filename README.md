# NeuroFoldNet: leakage-safe fusion of unpaired tau-oligomer assays

Code, result files and a frozen model accompanying the manuscript *"NeuroFoldNet: leakage-safe fusion of
unpaired tau-oligomer assays separates Alzheimer's disease, dementia with Lewy bodies, and progressive
supranuclear palsy preparations"* (under double-blind review).

The analysis re-uses public data:
* the source-data workbook of Lo Cascio *et al.*, *Commun. Biol.* 8:53 (2025)
  (`42003_2025_7499_MOESM3_ESM.xlsx`, CC BY 4.0)
* the companion single-cell RNA-seq dataset, GEO accession **GSE277105**

No synthetic data are used.

## Design principles

1. **Each assay is read exactly as laid out in the workbook.** There is no imputation, interpolation or
   broadcasting. The workbook has no sample identifier shared between figures, so assays are never merged
   into one per-sample feature vector.
2. **Every fitted step happens inside training folds**: scaling, hyperparameter search and model fitting.
3. **Group-aware splits.** Spectra are grouped in contiguous acquisition blocks of 10. The Fig. 7
   transcriptomic model is tested on a held-out mouse genotype.
4. **Inference, not only point estimates**:
   * cluster-bootstrap 95% CIs
   * whole-pipeline label-permutation tests
   * Nadeau–Bengio corrected t-tests
   * Holm correction
5. **Full metric panel**:
   * accuracy, balanced accuracy, macro-F1, macro one-vs-rest ROC-AUC, log loss, Brier score
   * per-class sensitivity (recall), specificity, precision and F1

## NeuroFoldNet

NeuroFoldNet is a two-level framework for combining assays that were never measured on the same sample.

* **Level 1, assay experts** (`neurofoldnet/models.py`, `scripts/run_morphology_models.py`):
  * a tuning-free spectral soft-voting ensemble (shrinkage LDA, RBF-SVM and random forest on the spectrum,
    plus logistic regression on nine shape descriptors)
  * a morphology kernel-density expert, with particles reconstructed uniformly within histogram bins so
    the per-disease bin grid cannot leak the label
  * a regularised seeding classifier
* **Level 2, unpaired evidence fusion** (`scripts/run_multiassay_panel.py`): a fixed, unweighted sum of
  out-of-fold mean log posteriors per preparation. This is the product rule (Kittler et al., 1998)
  applied at preparation level. It needs no pairing across assays and has no fitted weights. Majority
  voting is reported as a baseline.

## Reproduce

```bash
pip install -r requirements.txt
# download GSE277105_counts.csv.gz and GSE277105_metadata.csv.gz from GEO into data/figure7_geo/
python scripts/build_fig7_sparse.py               # once, about 8 min
python scripts/run_assay_models.py                # about 2.5 h with permutations (--quick for a smoke test)
python scripts/run_morphology_models.py
python scripts/run_multiassay_panel.py            # needs the two scripts above
python scripts/run_fig7_cross_genotype.py
python scripts/run_spectral_preprocessing_sensitivity.py
python scripts/run_assay_statistics.py
python scripts/export_paper_numbers.py
python scripts/audit_legacy_pipeline.py
```

Seeds are fixed throughout.

## External validation with the frozen model

No public dataset measures these assays on independent AD, DLB or PSP material. The frozen experts and
fusion rule can be applied to new data **without refitting**:

```bash
python scripts/neurofoldnet_external.py predict --spectra-dir new/spectra --morphology new/afm.csv --seeding new/seeding.csv --out preds.csv
```

Input formats are in `models/templates/`. Any subset of assays and any subset of diseases can be supplied.
To regenerate the frozen model from the source data, run `python scripts/neurofoldnet_external.py freeze`.

## Limitations

* The source study used three donor brains per disease. The released data do not link measurements to
  donors, so the results describe **separability of disease-derived preparations, not patient-level
  diagnosis**.
* There is no independent external cohort. The held-out genotype is a held-out biological context, not an
  external patient cohort.
* Fig. 1, 3, 5 and 6 are released as histograms, curves or summary statistics.

## Legacy

`legacy/` holds an earlier pipeline for audit only. Its reported accuracy came from three leakage
sources:
* histogram bin centres used as per-sample features
* class-constant summary values used as features
* a constant Figure 7 column

`scripts/audit_legacy_pipeline.py` documents each issue. Do not use those results.
