Implementation:
- scripts/prepare_full_supplement_features.py summarizes disease-specific numeric blocks from Fig 1 through Fig 6.
- scripts/prepare_figure7_geo_features.py aggregates Figure 7 cells to sample/treatment-level pseudobulk profiles.
- scripts/merge_tau_and_geo_features.py can join either the original tau table or the expanded full-supplement table with GEO summaries.
- train.py supports tau_full_supplement and tau_full_supplement_plus_geo feature modes.

Exploratory model search:
- results/expanded_model_search.csv stores fold-local classifier comparisons.
- Several simple classifiers reach 100% accuracy when using disease-level full-supplement summaries.
- This is not appropriate as the main performance claim because the added full-supplement and GEO features are disease-level auxiliary descriptors, not matched sample-level measurements.

Interpretation:
The expanded features strengthen biological characterization and can be described as a full-supplement exploratory feature expansion. The defensible primary claim should remain tied to the grouped NeuroFoldNet CV results and should clearly state that full-supplement/GEO additions are disease-level auxiliary summaries.
